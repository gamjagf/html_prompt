HTML 바이브코딩 프로젝트

나만의 꿈나라 홈페이지 만들기

초등학생이 어려운 코드 용어를 외우기보다, 만들고 싶은 화면을 자연어로 설명하며 AI에게 부탁하는 연습을 하는 프로젝트입니다.

프로젝트 목표

30차시 동안 하나의 홈페이지를 조금씩 키워 갑니다. 학생은 HTML 용어를 몰라도 “어떤 화면을 만들고 싶은지”를 말로 설명하면서, AI가 코드를 만들어 주는 과정을 경험합니다.

프롬프트 공식: 어떤 페이지인지 + 무엇이 보이면 좋은지 + 어떤 느낌인지 + 어떻게 움직이면 좋은지
1

첫 웹페이지 만들기

처음 화면 만들기

결과: “민수의 꿈나라” 제목과 간단한 자기소개

나만의 꿈나라 홈페이지 첫 화면을 만들어줘. 화면 가운데에 “민수의 꿈나라”라는 큰 제목을 넣어줘. 그 아래에는 내가 좋아하는 것과 나의 꿈을 소개하는 짧은 문장 2개를 넣어줘. 초등학생이 만든 것처럼 밝고 쉬운 느낌이면 좋겠어.

2

글자 꾸미기

소개 내용을 보기 좋게 나누기

결과: 꿈, 취미, 좋아하는 것을 구역별로 정리

나만의 꿈나라 홈페이지에 내 소개를 보기 좋게 정리해줘. 큰 제목에는 나의 이름을 넣고, 작은 제목에는 나의 꿈과 취미를 나누어 보여줘. 중요한 단어는 더 눈에 잘 띄게 해줘.

3

색깔 넣기

밝고 귀여운 색상 적용

결과: 밝고 귀여운 꿈나라 색상 적용

나만의 꿈나라 홈페이지를 밝고 귀여운 색으로 꾸며줘. 배경은 부드러운 색으로 하고, 제목은 눈에 잘 띄게 만들어줘. 초등학생이 보기에 따뜻하고 편안한 느낌이면 좋겠어.

4

사진과 링크

사진 자리와 링크 넣기

결과: 프로필 사진과 참고 사이트 링크

나만의 꿈나라 홈페이지에 프로필 사진이 들어갈 자리를 만들어줘. 사진 아래에는 내가 좋아하는 영상이나 검색 사이트로 이동할 수 있는 글자 링크를 넣어줘. 사진이 없어도 나중에 쉽게 바꿀 수 있게 만들어줘.

5

버튼과 목록

좋아하는 것과 응원 버튼

결과: 좋아하는 것 목록과 응원 버튼

홈페이지에 내가 좋아하는 것들을 보기 좋게 정리해줘. 좋아하는 음식, 좋아하는 게임, 좋아하는 동물을 목록으로 보여줘. 아래에는 “응원하기” 버튼도 하나 만들어줘.

6

표 만들기

나의 꿈을 비교해 보여주기

결과: 나의 꿈과 이유를 표로 정리

나의 꿈을 한눈에 볼 수 있게 정리해줘. 나의 꿈, 그 꿈을 갖게 된 이유, 앞으로 해보고 싶은 일을 깔끔하게 비교해서 보여줘. 친구들이 봐도 쉽게 이해할 수 있게 만들어줘.

7

입력창 만들기

친구 응원 메시지 공간

결과: 친구 응원 메시지 입력창

친구들이 내 꿈을 응원하는 메시지를 남길 수 있는 공간을 만들어줘. 이름을 적는 칸, 응원 메시지를 적는 칸, 보내기 버튼을 넣어줘. 입력칸 안에는 무엇을 적어야 하는지 안내 문구도 넣어줘.

8

미니 홈페이지 완성

홈페이지 전체 정리

결과: 제목, 사진, 소개, 목록, 버튼, 입력창 통합

지금까지 만든 내용을 하나의 나만의 꿈나라 홈페이지로 정리해줘. 제목, 사진 자리, 자기소개, 좋아하는 것 목록, 응원 버튼, 메시지 입력창이 자연스럽게 이어지게 만들어줘.

9

박스 레이아웃

카드형 구역 나누기

결과: 구역이 나누어진 홈페이지

홈페이지 내용을 여러 구역으로 나누어줘. 첫 번째 구역은 제목, 두 번째 구역은 자기소개, 세 번째 구역은 나의 꿈, 네 번째 구역은 친구 응원 메시지 공간으로 만들어줘. 각 구역은 카드처럼 보기 좋게 구분해줘.

10

hover 버튼

반응하는 버튼 만들기

결과: 마우스를 올리면 색이 변하는 버튼

응원하기 버튼을 더 재미있게 만들어줘. 마우스를 버튼 위에 올리면 색이 바뀌고 조금 더 눈에 띄게 해줘. 버튼은 둥글고 크게 만들어서 초등학생도 쉽게 누를 수 있게 해줘.

11

사진 슬라이드

자동으로 바뀌는 사진 화면

결과: 꿈 이미지가 자동으로 바뀌는 배너

꿈과 관련된 사진이 자동으로 바뀌는 화면을 만들어줘. 3장의 사진이 2초마다 하나씩 바뀌게 해줘. 사진이 바뀔 때 너무 딱딱하지 않고 자연스럽게 보이면 좋겠어.

12

메뉴와 다크모드

열고 닫히는 메뉴와 화면 분위기 변경

결과: 숨겨진 메뉴와 다크모드 버튼

버튼을 누르면 숨겨진 메뉴가 열리게 만들어줘. 다시 누르면 메뉴가 닫히게 해줘. 또 화면 분위기를 밝은 느낌과 어두운 느낌으로 바꿀 수 있는 버튼도 만들어줘.

13

로그인 화면

꿈나라 입장 화면

결과: 꿈나라 입장 로그인 화면

꿈나라에 들어가는 로그인 화면을 만들어줘. 아이디를 적는 칸, 비밀번호를 적는 칸, “입장하기” 버튼을 넣어줘. 버튼을 누르면 “꿈나라에 오신 것을 환영합니다!”라는 안내창이 나오게 해줘.

14

이미지 갤러리

사진 카드 전시하기

결과: 꿈 사진 카드 갤러리

나의 꿈과 관련된 사진들을 카드처럼 보기 좋게 전시해줘. 각 카드에는 사진과 짧은 제목을 넣어줘. 마우스를 올리면 카드가 살짝 떠오르고 사진이 조금 커지게 해줘.

15

원페이지 사이트

한 페이지 안에서 이동하기

결과: 메뉴를 누르면 해당 구역으로 이동

나만의 꿈나라 홈페이지를 한 페이지 안에서 이동할 수 있게 만들어줘. 위쪽 메뉴에는 홈, 소개, 꿈, 갤러리, 응원하기를 넣어줘. 메뉴를 누르면 해당 위치로 부드럽게 이동하게 해줘.

16

모바일 최적화

휴대폰에서도 보기 좋게 만들기

결과: 스마트폰에서도 잘 보이는 페이지

홈페이지를 컴퓨터와 휴대폰에서 모두 보기 좋게 만들어줘. 컴퓨터에서는 카드가 가로로 보이고, 휴대폰에서는 카드가 한 줄씩 세로로 보이게 해줘. 글씨가 너무 작아지지 않게 해줘.

17

CSS 애니메이션

부드러운 움직임 넣기

결과: 둥실 움직이는 버튼과 반짝이는 제목

홈페이지 첫 화면이 살아 있는 느낌이 나게 만들어줘. 제목은 천천히 나타나고, 응원하기 버튼은 살짝 둥실둥실 움직이게 해줘. 너무 정신없지 않고 부드러운 움직임이면 좋겠어.

18

Transform 효과

입체적인 카드 느낌 만들기

결과: 3D 느낌 카드와 눌리는 버튼

꿈 소개 카드를 더 입체적으로 보이게 만들어줘. 마우스를 올리면 카드가 살짝 커지고 조금 기울어지는 느낌이 나게 해줘. 버튼을 누를 때는 실제로 눌리는 것처럼 보이게 해줘.

19

유튜브 영상 넣기

영상 공간 만들기

결과: 꿈과 관련된 영상 카드

나의 꿈과 관련된 영상을 넣을 수 있는 공간을 만들어줘. 영상은 카드 안에 보기 좋게 들어가게 해줘. 휴대폰으로 봐도 영상이 화면 밖으로 나가지 않게 만들어줘.

20

Grid 갤러리

사진 전시관 만들기

결과: Pinterest 스타일 꿈 갤러리

나만의 꿈나라 사진 전시관을 만들어줘. 사진과 카드가 많아져도 자동으로 예쁘게 정렬되게 해줘. 사진을 벽에 붙여 놓은 전시관처럼 보기 좋게 보여줘.

21

반응형 웹사이트 심화

기기별로 보기 좋게 정리

결과: PC 4칸, 태블릿 2칸, 모바일 1칸으로 바뀌는 꿈 카드 갤러리

꿈 카드 갤러리를 컴퓨터, 태블릿, 휴대폰에서 모두 보기 좋게 만들어줘. 컴퓨터에서는 카드가 여러 개 보이고, 태블릿에서는 조금 적게 보이고, 휴대폰에서는 한 줄에 하나씩 보이게 해줘. 사진은 찌그러지지 않게 해줘.

22

움직이는 UI

게임 시작 화면 같은 움직임

결과: 로딩 원, 천천히 나타나는 제목, 움직이는 시작 버튼

꿈나라 첫 화면에 움직이는 효과를 넣어줘. 로딩 표시가 빙글빙글 돌고, 제목은 천천히 나타나고, 시작 버튼은 부드럽게 움직이게 해줘. 게임 시작 화면처럼 설레는 느낌이면 좋겠어.

23

위치 고정 UI

계속 보이는 메뉴와 버튼

결과: 상단 고정 메뉴, 배너 위 문구, 화면 아래 TOP 버튼

홈페이지를 아래로 내려도 위쪽 메뉴가 계속 보이게 해줘. 큰 사진 위에는 소개 문구가 겹쳐 보이게 해줘. 오른쪽 아래에는 언제든지 맨 위로 올라갈 수 있는 TOP 버튼을 고정해줘.

24

CSS 변수와 테마

색상을 쉽게 바꾸는 구조

결과: 색상을 한곳에서 관리하는 꿈나라 디자인 시스템

홈페이지 색상을 나중에 쉽게 바꿀 수 있게 만들어줘. 배경색, 카드 색, 버튼 색, 글자 색을 한곳에서 관리할 수 있게 해줘. 색을 바꾸면 전체 분위기가 함께 바뀌게 해줘.

25

JavaScript 클릭 이벤트

버튼을 누르면 안내창 표시

결과: 버튼을 누르면 환영 메시지가 뜨는 페이지

꿈나라 입장하기 버튼을 만들어줘. 버튼을 누르면 “꿈나라에 오신 것을 환영합니다!”라는 안내창이 나오게 해줘. 초보자도 이해하기 쉬운 코드로 만들어줘.

26

글자 내용 바꾸기

버튼을 누르면 문장 변경

결과: 버튼을 누르면 소개 문장이 바뀌는 화면

버튼을 누르면 소개 문장이 다른 문장으로 바뀌게 만들어줘. 처음에는 “버튼을 눌러보세요”라고 보이고, 버튼을 누르면 “나는 미래의 꿈을 향해 출발합니다!”라고 바뀌게 해줘.

27

JavaScript 변수

정보를 저장해 보여주기

결과: 이름, 나이, 꿈을 변수에 저장하고 출력

이름, 나이, 장래희망을 저장해 두고 버튼을 누르면 보여주는 자기소개 기능을 만들어줘. 예를 들어 “제 이름은 민수이고, 나이는 11살이며, 꿈은 과학자입니다.” 처럼 나오게 해줘.

28

사용자 입력받기

이름과 꿈 입력받기

결과: 사용자가 이름과 꿈을 직접 입력하는 프로그램

사용자가 직접 이름과 꿈을 입력할 수 있게 만들어줘. 이름을 입력하고, 장래희망을 입력하면 “민수님의 꿈은 과학자입니다. 응원합니다!” 처럼 메시지가 나오게 해줘.

29

HTML 화면에 출력하기

입력한 내용을 화면에 보여주기

결과: 입력한 자기소개가 웹페이지 안에 직접 표시됨

사용자가 입력한 자기소개를 알림창이 아니라 홈페이지 화면 안에 보여줘. 이름, 나이, 좋아하는 것, 장래희망이 줄을 바꿔서 보기 좋게 표시되게 해줘.

30

여러 개의 버튼

여러 버튼으로 내용 바꾸기

결과: 이름, 취미, 꿈 버튼을 누를 때마다 다른 내용 표시

홈페이지에 여러 개의 버튼을 만들어줘. 이름 보기, 취미 보기, 꿈 보기, 좋아하는 음식 보기 버튼을 넣어줘. 각 버튼을 누르면 화면 안에 서로 다른 내용이 나오게 해줘.

학생용 최종 프롬프트 템플릿

아래 문장을 복사한 뒤, 괄호 안의 내용을 학생이 직접 바꾸게 하면 좋습니다.

초등학생이 만든 것처럼 쉽고 예쁜 HTML 홈페이지를 만들어줘. 주제는 [나의 꿈]이고, 큰 제목은 [나만의 꿈나라]로 해줘. 사진이 들어갈 자리, 자기소개, 좋아하는 것 목록, 응원 버튼, 친구가 메시지를 남기는 공간을 넣어줘. 밝고 귀여운 느낌으로 만들고, 휴대폰에서도 보기 좋게 만들어줘.
